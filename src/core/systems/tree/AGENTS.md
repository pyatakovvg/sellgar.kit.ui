# Tree traversal

Внутренний механизм для NewSelect.Tree, NewSelect.Multiple.Tree и
NewSelectList.Multiple.Tree. Не является
компонентом выбора и не экспортируется из основного entrypoint кита.

- Обходит полную иерархию через resolveChildren без требования поля children.
- Сохраняет идентичность строк по исходным опциям, независимо от resolveKey.
- Хранит только раскрытие и активную строку; value и каскадного выбора здесь нет.
- Disabled ветвь делает поддерево недоступным для выбора, но не для раскрытия.
- Возвращает плоские видимые строки с явными level/position/siblings metadata.
- Left/Right управляют ветвями. В селектах Up/Down/Home/End и scroll использует
  Floating.List; в самостоятельном списке — локальный DOM-фокус и Scrollbar.
- defaultExpanded по умолчанию true: все ветви раскрыты. false задаёт полностью
  свёрнутое начальное дерево, в том числе при выбранном листе.
- Начальный режим фиксируется при монтировании; изменения prop не управляют
  текущим раскрытием. В state хранятся базовый режим и переключённые id.
  Новые узлы наследуют начальный режим, существующие сохраняют переключения.
- Открытие popup не сбрасывает ручное раскрытие и не раскрывает скрытый выбор.
