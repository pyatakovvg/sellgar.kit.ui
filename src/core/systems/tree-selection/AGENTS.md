# Каскадный выбор дерева

Общий внутренний механизм NewSelect.Multiple.Tree и NewSelectList.Multiple.Tree.
Не экспортируется из основного entrypoint кита.

- Чистые функции; не хранит value, раскрытие, фокус или DOM.
- Результаты выбора содержат только листья; недоступные поддеревья исключены
  из каскадного выбора и счётчиков.
- Частичный выбор ветви дополняется до полного; полный снимается.
- Значения других ветвей сохраняются. Сравнение результатов через isValueEqual.
- total — число доступных листьев во всём поддереве, включая вложенные ветви.
- Идентичность строк задаёт systems/tree, независимо от результата resolveKey.
