# Новое семейство списков выбора

Фасад NewSelectList экспортируется через @sellgar/kit. Сейчас реализован только
NewSelectList.Multiple.Tree. Остальные разновидности не создаются заранее.
Структура семейства повторяет new-select: фасады собирают самостоятельные
компоненты, не объединяют их props или состояние.

## Multiple.Tree

- Самостоятельный список для размещения в форме. Не использует Floating,
  popup, SelectInput, mobile sheet или приватные списки NewSelect.
- Применяется fe-react-component-structure; для generic-компонента согласовано
  объявление generic arrow function с приватным IProps вместо React.FC.
- resolveChildren задаёт иерархию; resolveValue возвращает string|number.
- resolveKey необязателен: onChange получает массив исходных опций либо
  произвольных результатов resolver. Объектные результаты сравнивает isValueEqual.
- value управляется потребителем; отсутствие value означает пустой выбор.
- systems/tree отвечает за идентичность, раскрытие и активную строку;
  systems/tree-selection — за каскадный выбор и производные состояния.
- Чекбокс/строка ветви выбирает доступные листья всего поддерева. Родительские
  checked/mixed вычисляются из value; ветви не попадают в onChange.
- Счётчик ветви показывает доступные листья на всех уровнях, включая вложенные
  ветви. Не зависит от раскрытия и выбора. Недоступное поддерево не учитывается.
- Недоступная ветвь блокирует выбор потомков, но раскрывается стрелкой и
  Left/Right. disabled всего списка блокирует также раскрытие и фокус.
- aria-disabled не ставится на раскрываемую ветвь: иначе она наследуется
  кнопкой раскрытия. Недоступность выбора задаётся на её checkbox.
- defaultExpanded по умолчанию true; false полностью сворачивает начальное
  дерево. Дальнейшие изменения prop не сбрасывают ручное раскрытие.
- renderOption заменяет содержимое строки; семантическая оболочка и клавиатура
  сохраняются. Кастомные элементы вызывают onCheck/onToggle из metadata и
  останавливают всплытие click, если обрабатывают его самостоятельно.
- TreeNode — приватный элемент коллекции. Получает готовую модель узла с
  производными состояниями и моделями детей, не ищет бизнес-опции по id.
- Стандартная строка — один готовый ExtendedOption: leadIcon с Button.Icon,
  label с готовым controlled Checkbox и подписью, badge со счётчиком.
  У листа leadIcon пустой, чтобы сохранить выравнивание. Собственных row/arrowSlot/
  checkbox-обёрток нет. Стандартные стили опшена не переопределяются.
- Локальные стили отвечают за группы и отступы уровней. Отдельная семантическая
  оболочка с focus-стилем нужна только для пользовательского renderOption.
- Между дочерними строками и между ветвью и группой нет дополнительного gap:
  вертикальные отступы уже включены в готовый ExtendedOption. Gap макета между
  голыми Checkbox Label не прибавляется повторно к полному опшену.
- Native click checkbox/label изолирован от выбора строки обработчиком готового
  опшена; pointerdown сохраняет фокус treeitem. DOM checked не меняется вручную.
- Строка — treeitem; вложенная group связана с ней через aria-owns, чтобы
  фокусируемая область ограничивалась строкой, а не всем раскрытым поддеревом.
- Единственная точка Tab; Up/Down/Home/End перемещают DOM-фокус по видимым
  доступным строкам. Disabled ветви участвуют в навигации для раскрытия.
- При удалении, скрытии или блокировке активной строки выбирается сохранившийся
  видимый предок либо ближайшая доступная строка. DOM-фокус восстанавливается
  только если принадлежал дереву; внешний фокус и disabled всего списка
  не перехватываются. Переподключение React ref само по себе не меняет фокус.
- Существующий Scrollbar прокручивает сфокусированную строку в видимую область.

## Проверка

TypeScript библиотеки, production build, scoped ESLint/Stylelint/Prettier.
Stories: Kit/Controls/NewSelectList/Multiple/Tree. Проверять каскад, mixed,
повторный выбор, disabled потомков, object result, readonly value, раскрытие,
стрелки клавиатуры, scroll и мобильную ширину; регрессии NewSelect.Multiple.Tree.
