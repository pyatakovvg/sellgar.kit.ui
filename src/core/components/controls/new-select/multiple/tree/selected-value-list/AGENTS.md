# SelectedValueList

Приватная визуальная коллекция выбранных листьев MultipleTreeSelect, перенесённая
из существующего multiple. Не хранит и не преобразует бизнес-value. Получает
исходные опции со стабильными внутренними id, string|number resolveValue,
renderSelectedOption/renderOverflow и команду удаления конкретного листа.
Стандартный вид использует Badge и существующую remove-иконку.
