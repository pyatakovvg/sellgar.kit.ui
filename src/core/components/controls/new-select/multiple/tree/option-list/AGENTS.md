# OptionList

Приватная коллекция видимых строк MultipleTreeSelect. Не хранит selection.
Состояния групп приходят вычисленными от владельца, события выбора и ARIA
подключает Floating.List. renderOption заменяет визуал строки, получая исходную
опцию и метаданные дерева. Для multi tree используется aria-checked, включая mixed.
Строка Все категории — технический treeitem верхнего уровня и разделитель.
Отступы строятся по ancestorIds; нет index keys и inline CSS. Внешний padding
учитывает рамку готового Option, сохраняя 36px строки и шаг вложенности 26px.
