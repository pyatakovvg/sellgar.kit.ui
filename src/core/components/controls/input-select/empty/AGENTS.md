# empty

Отображает состояние пустого списка InputSelect.

- Приватная часть самостоятельного InputSelect; не экспортируется из @sellgar/kit.
- Структура и стили основаны на соответствующей исходной части Select; оригинал не изменяется.
- Данные приходят через props, запросы и состояние выбора отсутствуют.
- Проверяется через родительский InputSelect на /store#store/create.
