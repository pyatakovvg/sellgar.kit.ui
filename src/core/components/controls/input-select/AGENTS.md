# InputSelect

Самостоятельный компонент одиночного выбора с поиском внутри панели.

- Основан на исходной структуре Select, но имеет собственные OptionList, Option, Empty, Placeholder, Surface и стили в этом каталоге.
- Не импортирует Select или его private children; существующие components и Floating не изменяются ради InputSelect.
- Переиспользует штатные Floating/SelectInput и Input без изменения их контрактов.
- value — объект или null; onChange возвращает объект или null.
- optionKey — идентичность, optionValue — подпись; эти поля имеют тип string или number.
- Поисковое поле находится вне listbox. Текст ввода — локальное UI-состояние; onSearch вызывается после debounce (600 мс по умолчанию). Запросы и объединение options принадлежат потребителю. loading/error управляют отображением реального состояния запроса.
- Таймер отменяется при новом вводе, закрытии и unmount. Очистка поиска вызывается сразу. Во время ожидания и запроса старая выдача недоступна для выбора. Плейсхолдер «Поиск…» сохраняется при debounce и loading до отображения результатов; панель не схлопывается между этими состояниями. Плейсхолдер и список выбираются одним условием по фактически отображаемым selectState.items. «Ничего не найдено» показывается только после завершения поиска без результатов. Индикатор загрузки расположен только в tailIcon поискового Input: Animate.Spin и Loader4FillIcon.
- Закрытие панели очищает поисковый текст. Новый поиск не меняет выбранный объект.
- Стрелки используют существующую навигацию Floating.Select; Enter подтверждает активную опцию и не отправляет форму, пробел и IME остаются вводом текста.
- Public facade экспортирует только InputSelect. Дочерние компоненты приватны.
- Проверки: TypeScript кита, сборка Admin UI, browser-сценарий /store#store/create.
