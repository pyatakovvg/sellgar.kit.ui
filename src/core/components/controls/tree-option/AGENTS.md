# TreeOption

Общее внутреннее отображение названия и глубины узла для SelectTree и
MultiSelectTree. Состояние выбора и события принадлежат controls-потребителям.
Не экспортируется через публичный `@sellgar/kit` API. Маркеры глубины скрыты от
accessibility tree; стили используют CSS Modules и существующие tokens.
