# Tree options

Чистый mapper для SelectTree и MultiSelectTree. Сохраняет исходный узел, ключ,
текстовое название, глубину, ключ родителя и ключи непосредственных детей.

Обход идёт сверху вниз в порядке исходного дерева. Ключи должны быть уникальны
во всём дереве. Не добавлять зависимости от UI или поведение выбора в mapper.
