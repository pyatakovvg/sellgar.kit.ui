# AGENTS.md

## Что это

Низкоуровневые внутренние utilities с реальным повторным использованием.

## Назначение

`tree-options/tree-options.mapper.ts` преобразует вложенные options в плоский
обход для SelectTree и MultiSelectTree, сохраняя связи родителей и детей.

## Как реализован

- Public `index.ts` отсутствует.
- Общий mapper используется обоими controls через прямой внутренний импорт.

## Public API и локальные файлы

- Public API отсутствует.
- Нельзя экспортировать этот каталог из `@sellgar/kit`.

## Фактическое поведение

- Обход дерева сохраняет исходные узлы и порядок вложенных options.

## Зависимости

- Utilities не должны импортировать `core`, `icons` или `features`.

## Правила изменений

- Не добавлять сюда helper, который нужен только одному компоненту.
- Не создавать `index.ts` без отдельного решения.

## Риски и точки внимания

- Основной риск — превратить `shared/utils` в неструктурированную свалку.
- Каждый новый файл должен иметь понятного потребителя и описанную ответственность.

## Проверка

- Запускать `../../node_modules/.bin/tsc -p tsconfig.json --noEmit --incremental false`.
