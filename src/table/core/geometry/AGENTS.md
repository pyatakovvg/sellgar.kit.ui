# Общая геометрия Table

- Чистый core без React, DOM, CSS и runtime. Все размеры и scroll — логические
  числа numbers; чтение и применение токенов остаются у браузерного адаптера/view.
- `table-layout.ts` согласует `core/pinning` и `core/layout`. Не переносит сюда
  формулы бюджета, инициализации pin или обычной направленной компенсации.
- Вход содержит обычное состояние всей видимой упорядоченной схемы и отдельные
  pinWidth по id. Pin исключаются из центра; внутри групп сохраняется порядок схемы.
- Видимый viewport задаёт бюджет pin. Необязательная surfaceWidth задаёт общую
  широкую поверхность; она не увеличивает бюджет. Центр получает оба остатка.
- Обычный LayoutAnchor относится только к центру и его текущему порядку. Его
  хранение и reconciliation по id принадлежат runtime/columns. При перестройке
  схемы runtime сохраняет запросы по id и сбрасывает индексные anchors.
- `projectColumns` применяет scroll к готовой геометрии без пересчёта ширин.
  Позиции viewport и shift не являются CSS px. Не применять -scroll хедера дважды.
- Невместимые состояния отклоняются без мутации. Центр без auto пока не поддержан.
  Overflow центра возвращается как факт, без новой политики поведения pin.
- Подключён к runtime/columns и view. pinInset — постоянный отступ от своей
  стороны, независимый от scroll; view применяет его через горизонтальный sticky.
  displayOffset применяется к pin в портальном Header. Clip описывает логическую
  видимость, но не должен управлять нативной прокруткой через React на каждом кадре.
  Стороны ручек и fallback viewport не определяются этим модулем.
