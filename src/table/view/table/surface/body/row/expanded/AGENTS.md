# Expanded Row Content

- Expanded отображает существующий renderer Expand и измеряет его естественную высоту.
- Состояние раскрытия и применение высоты принадлежат runtime, DOM-подписки browser-адаптеру.
- Не задавать вычисленную высоту самому измеряемому блоку.
- Внутренний ExpandedTableContext связывает вложенный Table с browser-адаптером родителя. Вложенность наследует scroll owners; отдельный Scrollbar внутри Expand не создаётся.
