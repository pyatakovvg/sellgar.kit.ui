# Индикатор загрузки Table

## Тип документа

Компонентный AGENTS: приватный ребёнок Surface.

## Назначение и граница ответственности

Отображает единый процесс загрузки, включая дозагрузку, через существующий ProgressBar. Не загружает данные, не знает framework, controller, query или retry.

## Как реализован

Loading читает только loading из environment Table; результат запроса принадлежит приложению. Внутренний hook синхронизирует таймер с переданным loading, reducer хранит только техническое состояние анимации. index.ts экспортирует исключительно Loading для Surface.

## Контракт и фактическое поведение

Индикатор появляется на время загрузки и её завершения поверх содержимого под header (или Empty), без резерва высоты. При loading=false после завершения анимации полоса и пустой промежуток отсутствуют. Полоса начинается с 0; каждые 200 мс целевое значение увеличивается по диапазонам: до 50 — на 10, до 80 — на 5, до 95 — на 1, затем на 0.25, с пределом 99. С учётом 200 мс перехода ширины заполнение достигает 50% примерно за 1.2 с, 80% — за 2.4 с в активной вкладке без задержек таймера. Это ускоренная адаптация диапазонов NProgress; движение между значениями сглаживает ProgressBar. Завершение loading переводит в 100 с коротким переходом ширины, через 200 мс начинается плавное исчезновение. Скрытие сохраняет последнее значение, чтобы полоса не отъезжала назад во время fade; новый cycle сбрасывает его при следующем запросе. Повторное loading=true отменяет завершение предыдущей анимации, remount ProgressBar по cycle сбрасывает ширину. В общем ProgressBar переход ширины изменён с 500 мс ease на 200 мс linear. Loading не переопределяет его нативные псевдоэлементы. Cleanup отменяет все таймеры и media subscription. При reduced motion ожидающий прогресс статичен, в скрытой вкладке обновления приостановлены. Численное значение имитируемое; accessibility использует aria-valuetext и aria-busy Table.

## Зависимости

React, core ProgressBar, environment экземпляра. Позиция, ширина и clipping принадлежат TableBrowser/TablePresentation. Loading не измеряет DOM и не применяет координаты через React.

## Правила изменений

Не экспортировать hook/reducer через фасад, не добавлять framework dependencies или собственный scroll owner. Видимая полоса не должна двигаться с колонками; индикатор не меняет высоту Header и Empty.

## Риски и технический долг

Проверять быстрое повторное включение loading, завершение независимо от результата запроса, пустой набор, обе оси scroll, transformed ancestors и reduced motion. Явный дополнительный долг не зафиксирован.
