# HeadCell

- Локальный элемент коллекции Header: получает геометрию колонки напрямую от владельца `map`.
- Владеет контейнером заголовка, подписью, выравниванием и layout-слотом ручки.
- Context текущей колонки ограничен экземпляром HeadCell; он передаёт актуальную модель локальным controls без дублирования состояния и поиска по id.
- `resize-handle` — приватный дочерний компонент с кнопкой, индикаторами и событием захвата. Не переносить его содержимое обратно в HeadCell.
- Фасад экспортирует только HeadCell; Context и ResizeHandle не являются public API Table.
- Header регистрирует содержимое для пробного измерения ширины только при
  column.measureContent=true. Явный minWidth задаёт нижнюю границу и не выключает измерение.

- Горизонтальные pin удерживаются нативным sticky по готовому pinInset; не
  компенсировать scroll через React transform. Непрозрачный фон и локальный z-index
  закрывают центр. В портальном Header pin получают постоянные displayOffset;
  scroll-transform применяется только к центральным ячейкам. Все размеры — numbers.

- Разделитель pin повторяет legacy Table: --numbers-3 только справа у последнего
  левого pin и слева у первого правого pin. Между pin одной группы полос нет.
  Разделитель numbers3 центрируется на геометрической границе через ::after;
  контент обрезается отдельно, ширина колонки не меняется.

- Grid placement и pin coordinates применяет browser TablePresentation; React inline geometry здесь не задавать.

- Середина ResizeHandle совпадает с границей и осью разделителя: внешний вынос
  равен половине ширины ручки. resizeEdge задаёт сторону. Локальный z-index всех
  заголовков назначает browser: центр и левые pin идут выше следующего заголовка,
  правые pin — выше предыдущего. Это сохраняет обе половины ручки над соседней
  ячейкой при transform портального хедера. Обе pin-группы всегда выше центра.
  Внешний stacking Table/Header не меняется.

- SortIndicator — отдельный приватный ребёнок, отражает ColumnSort snapshot.
  HeadCell владеет click/Enter/Space и aria-sort; вложенные controls, Popover и resize
  не вызывают сортировку. Сторона меню/индикатора определяется только выравниванием:
  при правом — перед подписью, иначе — после. Как в legacy header-cell,
  подпись с controls занимает свободное место (flex: 1 1 auto), текст внутри
  выровнен согласно align. Не собирать подпись и controls в компактную группу.
  Сторона ручки определяется только resizeEdge, независимо от выравнивания.
  Отступ от границы —
  стандартный numbers12, дополнительный резерв под ручку не добавляется:
  ручка центрируется на границе и не занимает место в flex-потоке.
- SortIndicator декоративный и его click переключает сортировку через Header;
  data-table-header-control помечает только меню и resize, не общий slot индикатора.

- Внутренний компенсатор не измеряет контент и не имеет controls. При положительной
  ширине сохраняет фон/разделители ячейки без контентных отступов; при нулевой не монтируется.
