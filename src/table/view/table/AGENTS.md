# React Table

- `Table` компилирует декларации, создаёт runtime/browser и владеет Context экземпляра. Generic render scopes остаются в этом слое.
- `surface` размещает единственную поверхность с изолированным stacking context, `header` — единственный интерактивный хедер в нативном потоке до порога и в локальном портальном слое рядом со Scrollbar во время закрепления, `body` — окно строк, `row/cell` — элементы коллекций. Header остаётся DOM-потомком своей таблицы и не переносится в document.body.
- По требованию пользователя локальные уровни: Surface z-index:0, Header z-index:1. Индекс хедера не поднимает таблицу над внешними слоями приложения.
- View получает состав виртуального окна из snapshot. Не рассчитывать здесь компенсацию ширин или опору прокрутки. Геометрические DOM-свойства принадлежат browser TablePresentation; не дублировать их через React inline styles. Layout effect согласует вновь смонтированные узлы до paint.
- Собственные CSS Modules принадлежат своим компонентам; `runtime/browser/numbers.ts` преобразует рассчитанные числа в токены темы. DOM-адаптер не импортирует View.
- Поверхность использует существующий kit `Scrollbar` через фасад компонента. Не добавлять собственную графику полос или нативную полосу. Browser-адаптер определяет фактический viewport по нативному overflow среди предков surface, без доступа к private selectors Scrollbar.
- Сохранять визуал прежнего Table, используя его токены и размеры. Расчёты и состояние прежнего Table не подключать.
- Scrollbar host обрезает содержимое по внутреннему радиусу рамки. Browser-адаптер переносит этот же контур в координаты fixed-хедера через CSS clip-path; контур не движется с горизонтально прокручиваемыми колонками.
- Публичный фасад компонента экспортирует Table. Верхний фасад @sellgar/kit/table явно
  экспортирует совместимые useCellData/useRowExpanded и ExpandTrigger; сами Context
  и runtime остаются приватными.
- Очистка browser resources обязательна при unmount и смене scroll owner. Хедер не клонируется. Его React portal target остаётся тем же DOM-контейнером; browser переносит контейнер между flow-slot и локальным overlay host, сохраняя фокус и состояние controls. Pointer capture принадлежит стабильному root Table.

- Row разделяет main Line и Expanded; состояние раскрытия и обе части высоты принадлежат runtime. Expanded измеряется отдельно через browser observer, scroll correction применяется владельцу прокрутки.
- Раскрытые Row остаются смонтированы вне обычного виртуального окна, чтобы состояние вложенного Table не терялось. Не считать это проверкой производительности произвольного числа одновременно раскрытых строк.
- Main Line владеет row handlers; вложенный Expanded расположен рядом с ним, поэтому события вложенных таблиц не всплывают в обработчик строки родителя.
- Line с primary click входит в Tab order и активируется Enter/Space через нативный element.click(). Не конструировать MouseEvent и не переименовывать публичный click payload. Отложенный click читает актуальный environment; guard учитывает ARIA controls и contenteditable.
- Empty измеряется browser observer как самостоятельный блок; его фактическая высота входит в snapshot.bodyHeight.
- Table внутри Expand входит в общую горизонтальную поверхность: внешний Surface создаёт единственный Scrollbar, вложенный Surface — обычный контейнер. Browser измеряет отступ вложенной таблицы и передаёт её минимальную ширину runtime родителя; выделенная ширина родителя не используется как минимальная, чтобы исключить обратную связь при расширении/сужении экрана.

- Горизонтальные pin удерживаются нативным sticky по готовому pinInset; не
  компенсировать scroll через React transform. Непрозрачный фон и локальный z-index
  закрывают центр. В портальном Header pin получают постоянные displayOffset;
  scroll-transform применяется только к центральным ячейкам. Все размеры — numbers.

- При каждом рендере Table заново читает состав data.nodes и tree children через
  постоянный RowIdentities. Не кешировать этот обход только по ссылке на массив:
  caller может повторно передать тот же массив после замены/вставки/удаления.
  Реестр объектов и runtime не пересоздаются; сохранение ID, disclosure, измерений
  и ручных ширин проверяется отдельно от обновления состава. Обход не заменяет
  подписку на источник данных: изменение массива без рендера само не запускает Table.

- Table создаёт независимый ColumnSort и связывает его snapshot с HeadCell. Данные
  и callback последней строки читаются из актуальной конфигурации. Сортировка не входит
  в resize-геометрию и не меняет Scrollbar.
- Контекст Cell оборачивает результат renderer, включая обычные children. Он содержит
  object identity, исходную строку, depth (legacy deps) и команды раскрытия.
- Последняя Line регистрирует первую ненулевую смонтированную ячейку, а не широкую
  строку целиком: горизонтальное переполнение не занижает intersection threshold.
  Смена виртуального набора, последнего rowId, options и scroll owner пересоздаёт observer;
  unmount/отключение освобождают его. Expanded content не является trigger.
