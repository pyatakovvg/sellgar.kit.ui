# React Table

- `Table` компилирует декларации, создаёт runtime/browser и владеет Context экземпляра. Generic render scopes остаются в этом слое.
- `surface` размещает единственную поверхность с изолированным stacking context, `header` — единственный интерактивный fixed-хедер рядом со Scrollbar вне собственного scroll viewport, `body` — окно строк, `row/cell` — элементы коллекций. Header остаётся DOM-потомком своей таблицы и не переносится в document.body.
- По требованию пользователя локальные уровни: Surface z-index:0, Header z-index:1. Индекс хедера не поднимает таблицу над внешними слоями приложения.
- View получает размеры, диапазоны и координаты из snapshot. Не рассчитывать здесь компенсацию ширин или опору прокрутки.
- Собственные CSS Modules принадлежат своим компонентам; `serializer/numbers.ts` преобразует рассчитанные числа в токены темы.
- Поверхность использует существующий kit `Scrollbar` через фасад компонента. Не добавлять собственную графику полос или нативную полосу. Browser-адаптер определяет фактический viewport по нативному overflow среди предков surface, без доступа к private selectors Scrollbar.
- Сохранять визуал прежнего Table, используя его токены и размеры. Расчёты и состояние прежнего Table не подключать.
- Scrollbar host обрезает содержимое по внутреннему радиусу рамки. Browser-адаптер переносит этот же контур в координаты fixed-хедера через CSS clip-path; контур не движется с горизонтально прокручиваемыми колонками.
- Публичный фасад компонента экспортирует только Table. Runtime, Context, hooks и локальные дети приватны.
- Очистка browser resources обязательна при unmount и смене scroll owner. Хедер не клонируется и не меняет parent при переходе в закреплённое состояние.

- Row разделяет main Line и Expanded; состояние раскрытия и обе части высоты принадлежат runtime. Expanded измеряется отдельно через browser observer, scroll correction применяется владельцу прокрутки.
- Раскрытые Row остаются смонтированы вне обычного виртуального окна, чтобы состояние вложенного Table не терялось. Не считать это проверкой производительности произвольного числа одновременно раскрытых строк.
- Main Line владеет row handlers; вложенный Expanded расположен рядом с ним, поэтому события вложенных таблиц не всплывают в обработчик строки родителя.
- Table внутри Expand входит в общую горизонтальную поверхность: внешний Surface создаёт единственный Scrollbar, вложенный Surface — обычный контейнер. Browser измеряет отступ вложенной таблицы и передаёт её минимальную ширину runtime родителя; выделенная ширина родителя не используется как минимальная, чтобы исключить обратную связь при расширении/сужении экрана.
